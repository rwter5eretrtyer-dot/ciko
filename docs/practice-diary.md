# Дневник практики (шаблон для правдивого заполнения)

> В требованиях 9 рабочих дней по 8 часов. Даты и конкретные выполненные действия необходимо подставить по факту и подтвердить коммитами/PR. Ниже — **план**, а не запись о якобы уже выполненных девяти днях.

| День | Планируемое содержание | Подтверждение |
|---|---|---|
| 1 | Тема, 3 роли, user stories, kanban | issue/PR/согласование |
| 2 | ER-схема, OpenAPI, UI-макеты, архитектура | схемы/Figma/коммит |
| 3 | Миграции PostgreSQL, seed, backend-фреймворк | PR и тест БД |
| 4 | Регистрация, JWT, RBAC, профиль | PR и интеграционные тесты |
| 5 | CRUD фильмов, жанры, frontend-router | PR и работающий UI |
| 6 | Поиск, фильтры, пагинация, загрузка медиа | PR, демонстрация |
| 7 | Избранное, отзывы, история, аналитика | PR и тесты |
| 8 | Docker, CI, тестирование, исправления | Actions, deployment |
| 9 | Документация, отчёт, слайды, защита | PDF, PPTX, демо |

Записи руководителя, его подпись, аттестационный лист и характеристику заполняет уполномоченное лицо.
