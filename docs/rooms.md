# Комнаты Ciko

## Возможности

Зарегистрированный пользователь любой роли может создать комнату, пригласить людей по коду, загрузить MP4/WebM/OGG или указать URL. Гости входят по коду. Гости могут писать в чат. Управление прямым видеопотоком разрешено только создателю.

## Зачем три таблицы

- `rooms`: создатель, фильм или ссылка, код, состояние воспроизведения.
- `room_members`: связь многие-ко-многим пользователей и комнат.
- `room_messages`: сообщения участников с автором и временной меткой.

Все таблицы создаёт `002_rooms.sql`, она применяется после `001_initial.sql`. Схема существующей БД сохраняется.

## Доступ

Для каждого запроса к комнате сервер проверяет участника через `room_members`. Код комнаты позволяет войти, но сам по себе не даёт право читать закрытую переписку. Управление воспроизведением, переименование и удаление доступны только создателю комнаты.

## Синхронизация

Создатель отправляет событие `PUT /api/rooms/{id}/state` при play, pause, seek. Сервер хранит позицию, состояние и время события. Клиенты получают актуальную позицию через `GET /api/rooms/{id}` каждые 2,5 секунды. Если расхождение больше 2,5 секунд, позиция выравнивается. Для YouTube/Vimeo это не работает: встраиваемые плееры не контролируются через обычный HTML5 video API.

## Демо-сценарий защиты

1. Открыть Ciko, войти зрителем.
2. Перейти в «Комнаты», выбрать фильм «После света» и создать комнату.
3. Скопировать код.
4. Войти другим аккаунтом в окне инкогнито и присоединиться по коду.
5. Запустить видео в первом окне; показать синхронизацию во втором.
6. Написать сообщение и увидеть его в обеих вкладках.
7. Попробовать управлять видео от лица гостя и объяснить RBAC.
