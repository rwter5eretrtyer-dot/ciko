# Ciko — отчёт о тестировании

Дата подготовки: 15.11.2026. **Статус:** тесты написаны, но ещё не запущены. В текущей среде нет Docker и доступа к npm, поэтому нельзя честно указать «пройдено». Запустить их нужно локально или через CI и добавить фактические результаты.

## 1. Unit-тесты

Файл: `backend/tests/security.service.test.ts`. Проверяются 3 роли, полномочия редактора и администратора, SHA-256, генерация токенов, JWT access/refresh, HTTP URL, видеоформаты, YouTube/Vimeo и отказ при запрещённых ссылках.

**Команда:** `cd backend && npm run test:coverage`

Критерий преподавателя: ≥60% покрытия сервисного слоя. Порог указан в `vitest.config.ts`, но фактический процент появится только после запуска.

## 2. Интеграционные тесты

Файл: `backend/tests/integration.test.ts`. Пять сценариев c настоящей PostgreSQL:

1. API health общается с БД и возвращает 200.
2. Регистрация создаёт нового пользователя `viewer` с токеном.
3. Зритель получает HTTP 403 при попытке добавить фильм — серверный RBAC.
4. Неверный пароль возвращает HTTP 401.
5. Каталог отдаёт список с серверной пагинацией.

**Команда:** `cd backend && npm run test:integration`. Нужны тестовая БД и переменные окружения.

## 3. Тесты фронтенда

Файл: `frontend/src/components/MovieCard.test.tsx`.

1. Отображает название фильма и год.
2. Ссылка ведёт на корректный URL `/movie/:id`.
3. Кнопка избранного вызывает callback с ID фильма.

**Команда:** `cd frontend && npm run test`.

## 5. Дефекты и исправления

При первом прогоне запишите реальные ошибки, номер задачи, commit SHA/PR и результат повторного теста. Не вписывайте вымышленные дефекты: преподаватель может попросить показать исправление.
