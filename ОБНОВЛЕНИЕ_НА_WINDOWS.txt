CIKO 2.0. Обновление уже запущенного проекта на Windows

1. Откройте VS Code, папку C:\ciko.
2. В терминале выполните:
   docker compose down
   ВАЖНО: не добавляйте -v, иначе удалятся база и загруженные видео.
3. Сохраните файл C:\ciko\.env. Он не должен исчезнуть.
4. Распакуйте новый ZIP и скопируйте его папку ciko поверх C:\ciko.
   Подтвердите замену старых файлов. Не удаляйте .env.
5. Дважды нажмите C:\ciko\START_CIKO.bat.
6. После запуска откройте http://localhost:8080.
   Если браузер показывает старый интерфейс, нажмите Ctrl+F5.

При первом запуске применяется миграция 002_rooms.sql. Таблицы старого проекта не удаляются.

Если сборка выдаёт ошибку:
  docker compose logs --tail=100 api web db
Отправьте вывод терминала для точного исправления.

Проверка:
  http://localhost:8080/api/health
  http://localhost:8080/api/docs
